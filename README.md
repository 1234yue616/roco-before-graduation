## 发布与更新

本仓库保存编译后的静态游戏。`game-release.zip` 为原有完整基础包，`game-update.zip` 为相对于基础包累计生成的网页更新包；新增插画位于 `release-art/`。

发布流程严格校验基础包、累计更新包及新增插画的SHA256，先展开基础包，再覆盖更新网页和插画，最后部署到 GitHub Pages。资源基础路径为 `/roco-before-graduation/`。

同一次提交需更新网页ZIP、对应校验文件，以及发生变化的插画和 `release-art.sha256`。若更换基础包，同步重建累计更新包，避免覆盖回旧网页。发布用的素材不会放在开发依赖中。
