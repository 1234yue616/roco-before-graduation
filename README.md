## 发布与更新

本仓库保存编译后的静态游戏。`game-release.zip` 是完整基础包，包含网页、人物素材和 CG；`game-update.zip` 包含相对于基础包累计更新的文件。本轮美术素材保持原版，更新包仅替换网页文件。

发布流程分别检查两份压缩包的 SHA256，先展开基础包，再覆盖更新包，最后部署到 GitHub Pages。压缩包内的资源基础路径为 `/roco-before-graduation/`。

更新时，在同一次提交中替换 `game-update.zip` 与 `game-update.zip.sha256`。更新包必须相对于基础包累计生成，包含所有需要覆盖或新增的文件。若换成新的完整基础包，应同时移除旧更新包及其校验文件，或生成与新基础包对应的更新包。
